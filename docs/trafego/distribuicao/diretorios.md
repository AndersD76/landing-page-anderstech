# Diretórios e cadastros — 22 lugares

Cada link de site cadastrado é um caminho novo para o robô do Google chegar. Hoje o
domínio é novo e quase não tem links apontando para ele, e é por isso que só 16 páginas
estavam indexadas: não é problema de conteúdo, é de autoridade.

## Antes de começar — um ajuste de rota

O pedido original citava Capterra, G2 e Product Hunt. **Esses são diretórios de software,
e o anderstech.net é uma consultoria.** Cadastrar consultoria lá é rejeitado ou ignorado.

Quem pertence a esses diretórios é o **PrismaBiz**, que é SaaS de verdade. Deixei os três
numa seção separada no fim, marcados para o produto certo.

## UTM

Onde o diretório aceitar parâmetro na URL:

```
?utm_source=<diretorio>&utm_medium=listagem&utm_campaign=diretorios
```

Em diretório que não aceita, cadastre a URL limpa — link quebrado ou suspeito faz o
cadastro ser recusado, e o valor aqui é o link em si, não a medição.

## Ordem de execução

1. Google Business Profile — comece hoje, a verificação é o que demora

3. LinkedIn da empresa — 15 minutos
4. Confirmar o link no perfil da Unio
5. As quatro associações (5 a 12) — uma por dia
6. Os diretórios gerais numa sentada só

Depois de cada bloco, rode `npm run indexnow` para avisar o Bing de que o site tem
links novos apontando para ele.
